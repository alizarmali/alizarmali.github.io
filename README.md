# Ali Zarmali — Personal Landing Page

Static HTML/CSS/JS personal landing page for GitHub Pages.

## Files
- `index.html` — page structure and content
- `styles.css` — Executive Minimal visual system and responsive layout
- `script.js` — English/Persian language switcher
- `assets/` — profile and cinema images
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## Publish on GitHub Pages
1. Create a GitHub account and verify your email.
2. Create a public repository named `<your-github-username>.github.io` for a personal site.
3. Extract this ZIP. Upload the contents of `ali_personal_landing` to the **root** of the repository (so `index.html` is at the root).
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`, and save.
5. Your site will be available at `https://<your-github-username>.github.io/`.
